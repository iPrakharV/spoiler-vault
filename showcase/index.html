⚡ BlindSight Architecture & Twitch API Subsystems

BlindSight is an edge-adjacent, soft-realtime Twitch chat moderation and community prediction pipeline built with Node.js 20 LTS, TypeScript 5.8, Zod schema validation, and OpenAI Codex.

🟣 Twitch EventSub WebSocket

Persistent full-duplex socket to wss://eventsub.wss.twitch.tv/ws with heartbeat watchdogs, LRU deduplication (5,000 messages), and subscription reconnection recovery.

🔴 Twitch Helix Moderation SLA

Enforces PATCH /helix/chat/settings (6s non-mod delay). Deletes caught spoilers via DELETE /helix/moderation/chat before the 6.000s visibility deadline expires.

🤖 OpenAI Codex & GPT-4o

Strict JSON-Schema Constrained Decoding (chat_classification & story_map). User text isolated as untrusted data to guarantee immunity against prompt injection.

💾 SQLite WAL Journaling

Embedded ACID store running in Write-Ahead Logging (WAL) mode for <1ms concurrent reads and atomic serialized message claiming.

🎥 Twitch Clips API

Asynchronously fires POST /helix/clips?has_delay=true on stream reveals, capturing the live broadcaster reaction without blocking the 60 FPS overlay animation.

🛡️ Zod Runtime Contract Guard

Strict schema validation layer guarding inbound Twitch payloads, OpenAI structured outputs, and REST mutations against malformed payloads.
